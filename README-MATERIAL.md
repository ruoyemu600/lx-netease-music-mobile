- 迷你播放器：圆角悬浮容器、底部细进度、清晰文字层级、原生48dp操作区域；修复旧的音乐信息和抽屉方向闭包。
- 竖屏播放详情：自适应圆角方封面、歌曲标题下移、大圆角播放按钮、歌词正常流式布局、至少48dp进度触控区。保留封面旋转选项、歌词分页、歌手/专辑跳转、菜单、收藏、队列等既有交互。
- 进度手势保护：换歌、中断、零时长和未测得宽度时不发送旧歌曲进度。
- 新安装默认关闭上游版本自动检查，预览分支单独分发。

## 第二轮新增实现

- **底部三标签**：首页／搜索／音乐库，迷你播放器位于标签上方；键盘弹出时隐藏标签。页面首次访问才挂载，切换后保留搜索与滚动状态。竖屏跨业务页面滑动由底部导航替代，原歌曲/歌词等页面内部手势保留。
- **首页**：当前曲目封面和继续/暂停、每日推荐入口、收藏/历史/下载、真实本机歌单、去重后的最近五首播放记录；无数据展示明确空态，不编造推荐或统计。
- **音乐库**：歌单网格、本地歌曲、收藏专辑、关注歌手四分类；保留网易云歌单、OneDrive、下载管理及原列表管理入口。每分类只有单个 FlatList，不嵌套同向虚拟列表。
- **搜索**：56dp圆角框、音源胶囊、独立歌曲/歌单/歌手/专辑分类、48dp历史词条与操作区。
- **播放封面**：PagerView子页补明确尺寸；忽略瞬时零高度；优先使用播放器已解析封面并解包下载项，加入加载/失败/无图占位及旧图片回调保护。
- **返回优先级**：统一按当前路由分发内嵌详情返回，再返回所属根标签；隐藏缓存页不再竞争系统返回监听，避免依赖挂载顺序。
- 横屏支持新增首页/音乐库入口，搜索分类不重复出现；原横屏侧栏布局保留。

## 1.8.89：累计听歌统计

- 首页滚动内容最底部新增累计听歌卡：总时长、不同歌曲数、前三首排行；「每首歌收听时长」打开独立分页列表。
- 原生Media3的`player.isPlaying()`与Android单调时钟计时，不依赖首页计时器；暂停、缓冲、音频焦点抑制不计，拖动进度和倍速不虚增真实经过时间。无身份的占位音频不计。
- 按原始source+id累计。下载项解包原歌曲，线上与对应下载共用计数；不同来源ID不按歌名模糊合并，本地和OneDrive曲目也可记录。
- 独立SQLite事务增量存储，每10秒及暂停/切歌/停止提交。读统计通过只读peek，不为查询而创建播放器；数据库读写位于串行后台worker。
- 从启用本功能开始累计，不从旧history的播放位置倒推；只保存在本机，尚未纳入云同步或旧备份格式。系统卸载/清除App数据会清除此库，覆盖升级沿用同一数据目录。
- 强制杀进程可能损失末次未提交片段，通常约10秒；IO积压或持久化失败会扩大窗口。错误保留进程内pending并重试，UI保留上次成功结果，不伪装成零。
- UI每5秒只读刷新，仅首页在前台且未被其他原生页面覆盖时运行；后台真正计时仍由原生层负责。分页按累计时长排序，播放时可能重排，列表去重且可手动刷新。
- 复验：`npm run check:listening`（JDK17/Python3/Node）；包含真实javac计时边界、生产SQLite语句、身份/接口及组件生命周期mock。原生锁屏/焦点/强杀行为仍待真机验收。

## 验证入口

要求 Node 18+（优先使用仓库指定 Node 版本）。在项目根目录：

```bash
npm ci --no-audit --no-fund
npm run build:theme
npm run check:material
```

`check:material` 汇总主题/语法、导航挂载与返回、图标字形、封面/搜索、首页/音乐库数据及14项进度手势回归。组件/回调测试使用mock，仍非Android原生渲染测试。全仓TypeScript存量诊断仍保留；与上轮210项相比，本轮209项（去除了迷你播放器重复JSX属性），无新增诊断签名，比较时仅规范化翻译键union的打印变化，原始日志保留。

完整类型检查：

```bash
npx tsc --noEmit --pretty false
```

上游完整类型检查已有报错，请与原提交、相同锁文件和依赖环境比较新增错误，不通过删代码/关闭类型检查掩盖问题。阶段报告与原始日志随交付另附。

## 本机（ARM64 Android / proot）构建 APK

该环境已实际跑通完整构建并产出可安装的 ARM64 预览包，**不需要云端 CI**。

一条命令完成主题生成、UI 回归、补丁应用、原生编译、签名与结构校验，并把 APK 复制到下载目录：

```bash
bash scripts/build-local-apk.sh
```

默认输出 `/sdcard/Download/DSH-Go/lx-n-local-apk/LX-N-Material-v<版本>-arm64-<时间戳>.apk`。可用环境变量覆盖：`LX_LOCAL_BUILD_HOME`、`LX_HERMESC`、`LX_APK_OUTPUT_DIR`、`LX_BUILD_WORKERS`。

已验证的验收点（脚本内自动断言）：

- 应用标识 `com.lxnetease.music.mobile.material`，名称 `LX-N Material`，与原版数据隔离。
- v1/v2 签名校验通过（测试签名），ZIP CRC 与 16 KB 对齐通过。
- `classes.dex`、`resources.arsc`、65 个 `lib/arm64-v8a/*.so` 齐全。
- `assets/index.android.bundle` 为 Hermes 字节码，magic `0x1f1903c103bc1fc6`、版本 96。
- 第二轮本机完整脚本退出0，Gradle `BUILD SUCCESSFUL in 5m`；原始日志 `build-20261106-064528.log` 随交付报告定位。
- 脚本读取本次输出metadata，核对版本与ABI，避免版本升级后误选残留旧APK。

本机工具链组成（均在项目外的 `lx-n-local-build`，不污染仓库）：

| 组件 | 状态 |
| --- | --- |
| JDK 17 / Gradle 8.8 / SDK 35 | 已安装并实跑 |
| ARM64 AAPT2 / zipalign / aidl | 已通过真实 Android 35 资源链接 |
| NDK 26.1.10909125（ARM64 宿主） | 已通过 C/C++ 与 CMake 编译 |
| Hermes 0.12.0（HBC 96） | 由匹配 RN 0.73 源码编译，本机可用 |

三个必要的本机适配，均已落在脚本或 `local-maven.init.gradle`：

1. **Java 信任库**：系统缺少 cacerts，从系统公共 CA 生成独立信任库并注入 `JAVA_TOOL_OPTIONS`，保持 TLS 校验开启。
2. **Maven 路由**：本网络中 `repo.maven.apache.org` 返回 `*.azureedge.net` 证书，只把该主机重定向到同源的 `repo1.maven.org`；Google Maven 与插件门户保持原样。
3. **prefab staging产物缺失**：此主机的AGP流程没有生成预期的prefab库目录，导致 `CXX1210 No compatible library found`；独立CLI可成功生成，具体根因尚未证明。`scripts/patch-quick-base64.cjs` 让 `react-native-quick-base64` 改为直接编译 `ReactCommon/jsi/jsi.cpp`（与同项目的 quick-md5 一致）并关闭该模块 prefab，可重复执行。

仍然**未做**：安装、启动、播放、后台与视觉验收。脚本只保证安装包结构与签名正确。
